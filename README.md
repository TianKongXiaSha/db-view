# db-view

一个轻量的 MySQL 快速连接与 SQL 执行 Web 工具（Node.js 版，零依赖）：扫描指定目录下的所有文件（不限后缀，内容为 `mysql -h... -P... -u... -p...` 连接命令），支持模糊检索文件名，选中文件后自动解析连接命令并测试连接，随后可在页面上直接执行 SQL。

SQL 执行直接调用服务器本机的 **mysql 客户端**（无需 Python、无需 npm install，只要服务器有 node 和 mysql 命令即可）。

## 快速开始

```bash
# 1. 确认依赖（CentOS 7 自带 mysql 客户端；node 需 v14+）
node --version
mysql --version

# 2. 配置脚本目录（编辑 config.json）
{
  "scripts_dir": "/你的/连接文件目录",
  "server": { "host": "0.0.0.0", "port": 5001 }
}

# 3. 启动 / 停止 / 重启 / 状态
chmod +x run.sh
./run.sh start
./run.sh stop

# 浏览器打开 http://<服务器IP>:5001
```

也可以用环境变量覆盖目录：`SCRIPTS_DIR=/path/to/dir node server.js`

## 功能

1. **目录配置**：`config.json` 中的 `scripts_dir` 指定唯一读取目录，展示该目录（含子目录）下的所有文件（不限后缀，自动跳过隐藏文件）。
2. **模糊检索**：顶部搜索框输入关键字，实时按文件名（含相对路径）模糊过滤，命中部分高亮。
3. **自动连接**：点击文件后自动解析其中的 mysql 命令（支持 `-h/-P/-u/-p/-D`、长选项 `--host=...`、`-p` 紧跟密码或空格分隔、额外无值选项等），并调用 mysql 客户端执行 `SELECT VERSION()` 验证连通性，显示服务端版本。
4. **SQL 编辑与执行**：输入框内置 MySQL 语法高亮（关键字、函数、字符串、数字、注释分色）；输入字母即弹出联想，候选含关键字、函数、数据库名、当前库的表名与字段名，输入 `库名.` 或 `表名.` 可精确提示表与字段；`↑/↓` 选择、`Enter`/`Tab` 或鼠标点击采纳、`Esc` 关闭、`Ctrl/Cmd + Space` 手动触发。`Ctrl/Cmd + Enter` 或点击"执行"运行；支持分号分隔的多条语句；SELECT/SHOW 结果以表格展示，DML/DDL 返回影响行数。
5. **快捷命令**：预置"查看所有数据库 / 当前连接信息 / 查看当前库所有表 / 各库表数量统计 / 当前连接线程 / 字符集配置"，点击即执行；在 `static/app.js` 顶部 `PRESET_QUERIES` 数组中可自行增删。

## 实现说明

- SQL 通过 `mysql --batch -e "..."` 执行，输出为 TSV 格式，服务端解析后以 JSON 返回表格数据；密码通过 `MYSQL_PWD` 环境变量传递，避免出现在 `ps` 进程列表中。
- 无状态设计：每次执行都新建 mysql 进程（与 mysql 客户端交互习惯一致），因此 `USE db` / 临时表等会话级操作不会跨语句保留。
- 执行超时默认 60 秒；SELECT 结果最多返回所选行数（100~5000）。

## 注意

- 密码在页面与服务端响应中均已掩码显示。
- 该工具仅适用于内网可信环境，未做登录鉴权，请勿暴露到公网。
